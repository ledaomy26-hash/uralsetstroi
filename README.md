# Сайт ООО «Уралсетьстрой»

Сайт подрядчика по монтажу инженерных систем в жилой и коммерческой застройке
Екатеринбурга: отопление и теплоснабжение, водоснабжение и канализация,
индивидуальные тепловые пункты, вентиляция, электромонтаж, гидроизоляция.

Открыт по адресу **https://ledaomy26-hash.github.io/uralsetstroi/**

02.09.2026 на главный адрес поставлена вторая версия — та, что показана
заказчику. Первая версия убрана. Прежняя ссылка `/v2/` не сломана: там лежат
страницы-перенаправления на корень, и кто откроет её из старой переписки,
попадёт на тот же сайт.

## Как устроен

Статика без сборки и без серверной части: шесть страниц, один файл стилей,
один скрипт. Открывается двойным щелчком по `index.html`, переносится
на любой хостинг копированием папки.

| Файл | Что это |
|---|---|
| `index.html` | Главная. Интерактивный разрез здания: каждый раздел работ стоит там, где он находится на объекте |
| `uslugi.html` | Разделы работ, состав по каждому, порядок выполнения |
| `obekty.html` | Договоры 2026 года и сданные объекты |
| `kompaniya.html` | О компании и сведения для проверки контрагента |
| `kontakty.html` | Контакты и заявка на расчёт |
| `politika.html` | Политика обработки персональных данных |
| `404.html` | Страница на случай неверного адреса |
| `css/style.css` | Все стили. Палитра — в блоке `:root` в начале файла |
| `css/fonts.css` | Объявления шрифтов |
| `js/site.js` | Меню, листание по экранам, схема разреза, сборка заявки, счётчики |
| `fonts/` | Шрифты Cormorant, Onest, JetBrains Mono — лицензия SIL OFL |
| `img/` | Фотографии разделов, титульный кадр в двух размерах, знак в латуни |
| `logotip/` | Страницы показа логотипа и визитки — для заказчика, не часть сайта |
| `v2/` | Перенаправления со старой ссылки на корень |

## Листание по экранам

На широком окне с мышью (от 1240 px) страница разложена по экранам:
щелчок колеса переводит ровно на следующий, разделы не налипают друг
на друга. Раскладку считает `js/site.js` при загрузке и при смене размера
окна — руками в разметке ничего не размечено. На телефоне, на узком окне
и при системном «уменьшить движение» остаётся обычная прокрутка.

## Заявка с сайта

Серверной части нет, поэтому форма собирает введённое и открывает почтовую
программу или MAX посетителя с готовым текстом — отправляет он сам.
Адрес почты и номер задаются в начале `js/site.js` (`MAIL` и `PHONE`).
Без галочки согласия на обработку данных отправка не работает.

## Что нужно поменять на свои

- **Реквизиты** повторяются в подвале всех страниц — править в каждом файле.
- **Телефон и почта** — в подвале, в верхней строке, в шапке и в `js/site.js`.
- **Цвета и шрифты** — блок `:root` в начале `css/style.css`.
- **Фотографии** — в `img/` под теми же именами, разметку трогать не нужно.
