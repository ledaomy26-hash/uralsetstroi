# Сайт ООО «Уралсетьстрой»

Сайт подрядчика по монтажу инженерных систем в жилой и коммерческой застройке
Екатеринбурга: отопление и теплоснабжение, водоснабжение и канализация,
индивидуальные тепловые пункты, вентиляция, электромонтаж, гидроизоляция.

Открыт по адресу **https://ledaomy26-hash.github.io/uralsetstroi/**

## Как устроен

Статика без сборки и без серверной части: шесть страниц, один файл стилей,
один скрипт. Открывается двойным щелчком по `index.html`, переносится
на любой хостинг копированием папки.

| Файл | Что это |
|---|---|
| `index.html` | Главная. Интерактивный разрез здания: каждый раздел работ стоит там, где он находится на объекте |
| `uslugi.html` | Разделы работ, состав по каждому, порядок выполнения |
| `obekty.html` | Договоры 2026 года и сданные объекты |
| `kompaniya.html` | О компании и данные для проверки контрагента |
| `kontakty.html` | Контакты и заявка на расчёт |
| `politika.html` | Политика обработки персональных данных |
| `404.html` | Страница на случай неверного адреса |
| `css/style.css` | Все стили. Палитра — в блоке `:root` в начале файла |
| `css/fonts.css` | Объявления шрифтов |
| `js/site.js` | Меню, схема разреза, сборка заявки, счётчики цифр |
| `fonts/` | Шрифты Unbounded, Onest, JetBrains Mono — лицензия SIL OFL |
| `img/logo.png` | Логотип |

## Заявка с сайта

Серверной части нет, поэтому форма собирает введённое и открывает почтовую
программу или WhatsApp посетителя с готовым текстом — отправляет он сам.
Адрес почты и номер для WhatsApp задаются в начале `js/site.js`
(`MAIL` и `PHONE_WA`).

## Что нужно поменять на свои

- **Реквизиты** повторяются в подвале всех страниц — править в каждом файле.
- **Телефон и почта** — в подвале, в верхней строке, в шапке и в `js/site.js`.
- **Цвета и шрифты** — блок `:root` в начале `css/style.css`.
